# 대학교 협력·최적화 로드맵

터틀넥은 학교 서버에 부담을 주지 않는 로컬 우선 학습 도구를 목표로 합니다. 앞으로는 공개된 LMS 목록만 보고 지원 학교를 단정하지 않고, 각 대학교의 담당자와 협의해 실제 환경을 확인하고 최적화합니다.

## 목표

- 학교별 Moodle·Coursemos·Canvas 차이를 공식 협력 아래 확인합니다.
- 같은 자료를 반복해서 가져오지 않도록 캐시·변경 감지·요청 간격을 학교 환경에 맞춥니다.
- 학생 개인정보, 자격 증명, 원본 강의자료를 프로젝트나 외부 서버로 수집하지 않습니다.
- 읽기 전용 검증을 먼저 하고, 제출·업로드·강좌 수정 같은 쓰기 기능은 별도 승인과 확인 뒤에만 검토합니다.

## 진행 순서

### 1. 후보 학교 확인

공개된 Coursemos 기관 목록은 연락할 학교를 찾는 참고 자료로만 사용합니다. 목록의 등재만으로 현재 호환성이나 학교의 사용 승인을 의미하지 않습니다. 목록은 [공식 Google Play 기관 목록](https://play.google.com/store/apps/details?id=kr.coursemos.android2)과 [Coursemos 공식 사이트](https://www.coursemos.kr/)를 기준으로 갱신하고, 확인 날짜와 출처를 기록합니다.

### 2. 학교 담당자에게 협력 요청

학교의 정보전산원·LMS 운영 담당자 또는 공식 시스템 담당자에게 다음 범위로 협력을 요청합니다.

- 학생이 사용할 수 있는 공식 LMS 주소와 플랫폼·버전
- 테스트 가능한 샌드박스나 허가된 읽기 전용 계정
- 자동 조회·다운로드에 대한 학교 정책, 요청 간격, 점검 시간
- 허용되는 자료 범위와 보관 기간
- 장애나 과부하가 발생했을 때 사용할 연락 창구

비밀번호, 쿠키, 세션, 서명 URL, 개인 강좌 ID와 원본 자료는 요청하거나 전달받지 않습니다. 실제 계정이 필요할 때는 사용자가 자신의 기기에서 직접 로그인하고, 학교가 승인한 범위에서만 확인합니다.

### 3. 읽기 전용 호환성 확인

허가된 환경에서 강좌 목록, 주차·토픽, 공지, 과제, 강의, 파일 목록만 확인합니다. 결과에는 호스트, 활동 유형, 요청 수, 응답 크기, 소요 시간, 캐시 적중률과 오류·재시도 횟수만 남기고 강좌명·ID·본문·파일·인증값은 제거합니다.

학교별 결과는 다음 단계로 표시합니다.

| 단계 | 의미 |
| --- | --- |
| C0 | 문서·정적 구조만 확인 |
| C1 | 로컬 fixture/mock으로 공통 흐름 확인 |
| C2 | 민감정보를 제거한 응답 또는 HAR로 차이 확인 |
| C3 | 학교 담당자가 승인한 읽기 전용 환경에서 실측 완료 |

### 4. 학교별 최적화

확인된 차이만 별도 모듈과 fixture로 고정합니다. 기본 최적화 순서는 다음과 같습니다.

1. 같은 실행 안에서 이미 읽은 페이지 재사용
2. 바뀐 과목·활동만 상세 조회
3. 목록·과제/시청 상태·공지·자료의 확인 주기 분리
4. 로컬 파일·본문·분석 결과 재사용
5. 요청 간격, 재시도 상한, 서버가 요구하는 대기 시간 준수
6. 학교 담당자가 제공한 트래픽 또는 운영 지표가 있을 때만 서버 부하 개선을 주장

자료 원본과 동영상·음원은 자동 일괄 수집하지 않습니다. 필요한 범위만 사용자 확인 후 받고, 이미 검증한 로컬 사본을 우선 사용합니다. 업로드·백업 복구·대량 제출은 읽기 전용 최적화와 분리합니다.

### 5. 배포 판단

학교별 모듈은 다음 자료가 모두 있을 때만 “학교 협력 검증”으로 표시합니다.

- 승인 범위와 테스트 조건
- 민감정보가 제거된 fixture와 회귀 테스트
- 요청량·본문량·실행 시간의 비교 기록
- 실패 시 원본 보존과 재시도 제한 확인
- 학교별 지원 범위와 미지원 기능

협력이 없으면 해당 학교는 “표준 Moodle/Canvas 흐름 후보”로만 안내하며, 건국대 TLS 전용 동작이나 추정한 엔드포인트를 다른 학교에 적용하지 않습니다.

## 협력 결과의 공개 원칙

- 학교 이름과 담당자 정보는 공개 동의가 있을 때만 기록합니다.
- 학교 서버 주소를 공개하더라도 인증 정보·개인 데이터·서명된 주소는 공개하지 않습니다.
- 최적화 수치는 측정 조건, 캐시 상태, 로그인 제외 여부와 함께 적습니다.
- 학교 서버 CPU·메모리·DB 부하는 학교 측 측정값 없이는 추정하지 않습니다.
- 학교 정책과 충돌하거나 자동화 허가가 불분명하면 연결·다운로드·쓰기 기능을 중단합니다.

협력 제안이나 호환성 제보는 [GitHub Issues](https://github.com/K-Lunatic/Turtleneck/issues)를 기본 창구로 받습니다. 자격 증명이나 원본 자료는 이슈에 올리지 말고, 비공개 협의가 필요한 경우 먼저 비공개 연락이 필요하다고 알려 주세요.
