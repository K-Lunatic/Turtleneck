# 소량·대량 회귀 벤치마크

측정 시각: 2026-11-22 Asia/Seoul
환경: macOS 26.6.2, arm64, Python 3.11.6, 논리 코어 8개
커밋: `49e1ee3` · 각 시나리오 3회 중앙값 · 네트워크 사용 안 함

이 측정은 학교 서버 속도가 아니라, 같은 로컬 코드 경로가 대량 입력에서 중복 호출·처리시간·
체크포인트 문제를 일으키는지 확인하는 회귀 기준이다.

| 영역 | 소량 | 대량 | 증가 배율 | 입력 기준 |
| --- | ---: | ---: | ---: | --- |
| 학습 파이프라인 로컬 처리 | 94.51 ms | 284.10 ms | 3.01배 | 자료 1개 → 20개 |
| TLS 메타데이터 재사용 | 10.60 ms / 2요청 | 182.28 ms / 41요청 | 17.20배 | 과목 1개 → 40개 |
| 미디어 저장 | 1.05 ms / 3요청 | 177.22 ms / 1,001요청 | 169.26배 | 조각 2개 → 1,000개 |

## 해석

- 학습 파이프라인은 대량에서도 로컬 처리 시간이 입력 수에 따라 증가하지만, 캐시 재사용은
  소량·대량 모두 별도 AI 추출 없이 동작했다.
- TLS 메타데이터는 변경 없는 `ensure`에서 과목 수에 비례해 목록 확인이 늘어난다. 실제 서버
  부하는 이 fixture 결과로 추정하지 않으며, 실서버 측정은 별도 기록한다.
- 미디어는 조각마다 검증 요청이 필요하므로 대량 조각에서 요청 수가 선형 증가한다. 다만
  부분 파일과 체크포인트를 사용해 재시작 시 완료된 조각을 다시 받지 않는다.
