## 이번에 구현한 연결

- 학사·에타 데이터 조작은 기존 실행기/Provider로 경로를 명시했다. Browser Computer Use는 사용자가
  실제 화면 조작을 요청한 범위에서 사용한다. 로그인·시험 화면 표시는 계속 제공한다.
- `source-library`는 현재 프로필의 학교 자료와 공통 학습 문서를 검색한다. 목록은 기본 20개다.
  `source-document`는 출처·위치·본문을 저장하며 동일 자료를 재사용하고 수정본은 별도 ID로 남긴다.
  한 번 읽을 때 12,000자와 다음 위치를 반환한다.
- `selection.sourceDocumentId`가 기존 개념 학습·웹 시험의 자료 입력으로 연결된다.
- GradKUya 원본 로직에서 로컬 계산 엔진을 생성했다. 소스별 SHA-256을 manifest에 기록하고,
  F/NP 필수과목 처리와 입학연도 요람 선택을 보정했다. 실시간 학교 조회는 이 계산기에 포함하지 않는다.
- 보조 앱이 실행 중이면 로컬 로그인·시험·대시보드 화면을 앱 내부 창으로 요청한다. 실행 중인 앱이
  없거나 응답하지 않으면 기본 브라우저로 연다. 페이지 GET 확인과 열기 요청을 구분한다.
- URL 쿼리 비밀값 제거 패턴에서 값이 캡처에 남는 문제를 수정했다.
- 보조 앱의 기본 한국어·영어·중국어 선택과 선호 언어 저장, 호스트 AI의 문항·설명·채점 언어 계약을 추가했다.
  개념·후보 캐시는 언어를 구분하며, 번역본은 원문 ID와 출처·위치·순서를 보존해 별도 자료로 저장한다.
- Canvas API 결과를 사이트·계정 별칭별 로컬 SQLite에 저장하고 기존 프로필 선택·학사 조회 흐름에서 읽을 수 있게 했다.
  Canvas 토큰은 기존 TLS 비밀번호와 분리하며, 동기화 명령은 읽기 전용이다.
- TLS 과제 제출은 이미 제출 완료 상태를 다시 POST하지 않도록 보호하고, 명시적인 재제출 허용 없이는 중복 제출을 막는다.

## 이어서 구현할 순서

1. **노트 어댑터 완결**. 연결된 Notion 페이지/블록과 선택된 Notability 결과를 공통 자료 문서로 자동
   변환하고, Goodnotes PDF·로컬 파일도 같은 입력으로 가져온다. 미지원·부분 읽기·갱신을 명시한다.
2. **보조 앱 제품 흐름**. 학교 원본 자료 열기, 연결 관리, 비밀번호 재설정, 재시험, 앱/스킬/자료의
   삭제 선택을 같은 앱 흐름으로 마무리한다. 에타 공식 2차 인증은 기존 공식 브라우저로 유지한다.
3. **Canvas 범위별 갱신**. 현재 연결된 공통 DB 흐름에 과목·과제·공지·모듈·파일 목록의
   확인 시각과 범위별 캐시를 추가하고, 변경 없는 과목의 상세 API 요청을 건너뛴다. 제출·업로드는
   읽기 전용 원칙을 유지한다.
4. **GradKUya 배포 완결**. 선택 기능의 Node.js 준비·번들 포함 방법, 요람 업데이트, 프로필별 수강편람
   캐시를 연결한다. 학사 특례는 근거를 보관하고 확인이 필요한 항목으로 다룬다.
5. **미디어와 원격 쓰기 복구**. 조각 다운로드의 메모리 상한·임시 파일 정리·재시작을 정리하고,
   제출·업로드·복구의 중복 실행과 부분 실패 안내를 보강한다.
   기본 세 언어의 로그인·시험 고정 UI와 오류 문구를 완성하고, 추가 언어는 AI 번역 계약으로 연결한다.
6. **마지막 통합 검증·배포 산출물**. 깨끗한 macOS/Windows에서 설치→연결→수집→학습→앱/브라우저
   시험→재시작→업데이트→삭제까지 확인한다. 각 플랫폼 결과와 환경·시각을 기록한 뒤 릴리스한다.

  강의 중단·재시작과 Windows 파일 잠금은 아직 실기기에서 확인하지 않았다.
- 2026-11-17 스트리밍 원본 검증에서 파일 전체를 `read_bytes()`로 메모리에 올리던 경로를
  4KB 샘플 읽기로 바꿨다. 스트림의 `Content-Length`가 허용 상한을 넘으면 바이트 수신 전에
  중단하고, 정상 저장 시 flush·fsync까지 수행한다. 관련 미디어·자료 회귀와 전체 **513개
  통과·1개 건너뜀**을 확인했다. 장시간 실서버 중단·재시작은 아직 실기기에서 검증하지 않았다.
- 자율강좌 백업 복구의 multipart 업로드도 `.mbz` 전체를 메모리에 합치지 않고 파일 스트림을

  건너뜀**을 확인했다. 실제 TLS 자율강좌에 쓰기 요청을 보내는 검증은 아직 실행하지 않았다.

### 2026-11-17 최신 플랫폼 통합 검증

- 사용자 경험 회귀에서 확인된 다중 실행 로그인 중복을 보정했다. 여러 채팅·명령이 동시에
  세션 만료를 발견해도 프로필별 로그인 전용 `.auth` 잠금으로 한 번만 인증하고, 대기한
  실행은 잠금 해제 뒤 보호 저장 세션을 다시 확인해 로그인 폼을 반복하지 않는다. 기존
  동기화 잠금과 분리해 동기화 중 로그인에서 교착하지 않도록 했으며, 관련 인증 검사와
  전체 회귀 **529개 통과·환경 의존 2개 건너뜀**을 확인했다. 이 검사는 네트워크 없이
  로그인 재사용·실패 안내·시험 웹 열기·자율강좌 읽기·학습 캐시 흐름을 확인한 결과다.
- 자율강좌 문제은행 백업 생성기는 `.mbz`의 XML 제어 정보만 메모리에 읽고, 기존 활동의
  비XML 자료와 이미지를 tar 스트림으로 복사하도록 바꿨다. 큰 백업을 만들 때 전체 자료를
  `read()`로 합치지 않으며, 기존 활동 자료가 새 퀴즈에도 보존되는 회귀를 확인했다.
- 과거 저장 세션 실측에서 두 순차 응답의 정규화 결과가 일치하지 않아 `live-attempt.json`에
  `NOT_MEASURED`로 기록된 사례가 있었다. 이후 수강 취소된 과목을 보존 비교에서 제외하도록
  벤치마크 범위를 고쳤고, 최신 8과목 실측은 `live.json`에 성공 결과로 저장했다. 이 수치는
  메타데이터 전용·단일 계정·순차 단회 비교이며 학교 서버 CPU·DB 사용률을 의미하지 않는다.

## 보조 앱에서 AI 작업 요청

공식 문서를 확인한 설계 검토 단계이며 호출 코드는 아직 연결하지 않았다.
Codex App Server는 ChatGPT 관리 로그인과 대화 시작·재개·작업 이벤트를 제공한다. 로컬 오픈소스
보조 앱은 해당 공식 인증 흐름을 사용할 수 있으며, 인증 파일을 직접 읽거나 복사할 필요가 없다.
Claude Code는 `claude -p`와 구조화 응답을 제공한다. 실제 로그인 방식과 사용 한도는 설치된
클라이언트·사용자 계정에서 확인해야 한다. 별도 API 키를 요구하는 실행 모드도 있으므로 모드 선택을 구분한다.

MCP sampling은 연결 클라이언트의 지원이 필요하며 2026-07-28 규격에서 사용 중단 수순으로 들어갔다.
보조 앱의 새로운 작업 시작은 각 에이전트의 공식 호출 경로로 설계한다. 학습 데이터·문제 생성은
사용자가 선택한 자료 범위를 전달하고, 인증정보는 기존 Provider에 남긴다.
